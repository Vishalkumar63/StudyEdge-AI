# StudyEdge AI — Development Log

## Day 1 — September 15, 2026

### Project

StudyEdge AI — Private, On-Device AI Study Assistant

### Objective

Build an AI study assistant designed for Snapdragon-powered PCs.

### Initial Technology Decisions

- Programming Language: Python 3.11
- Development Environment: VS Code
- UI: Streamlit
- AI Model Ecosystem: Qualcomm AI Hub
- Snapdragon Deployment: QAI AppBuilder
- Hardware Acceleration: Snapdragon NPU
- Version Control: Git + GitHub

### Initial Features

1. PDF document upload
2. Document summarization
3. Question answering
4. Quiz/MCQ generation
5. Flashcard generation
6. Viva question generation

### Why This Project?

Students frequently use cloud-based AI tools to analyze academic documents. StudyEdge AI aims to explore a privacy-focused alternative using local AI capabilities on Snapdragon-powered PCs.
